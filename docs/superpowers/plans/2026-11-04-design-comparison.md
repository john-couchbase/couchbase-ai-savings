# Couchbase estimator design comparison

User authorized applying and comparing three design skills, improving spacing, buttons, and distinctiveness while retaining Couchbase colors and the guided flow.

## Decision
Use a Couchbase decision worksheet: left progress rail at desktop, responsive horizontal steps, flat form rows, red result, restrained outlined secondary controls. Preserve calculations and all disclosures. Alternatives considered: generic hero/features marketing page (poor task fit); purely gray Apple utility (insufficient brand identity).

## Three skill assessments
- Impeccable layout: independent visual/source assessment found inherited form borders, rounded progress geometry, flat spacing hierarchy, weak brand focal point. Detector found three advanced-disclosure padding warnings. Context launcher initially failed to download; direct project inspection used; detector retry succeeded.
- UI/UX Pro Max: `calculator enterprise minimal` returned Swiss minimalism but a generic marketing pattern/orange palette, rejected as a poor brand/task fit. Targeted touch-spacing query returned 8px gaps; active-state query reinforced explicit selected states. Keep native plain HTML/CSS/JS.
- Frontend Design: use subject-specific brand hierarchy and one deliberate focal point; remove redundant eyebrows, avoid decorative cards and ornamental motion. Preserve existing type for continuity.
